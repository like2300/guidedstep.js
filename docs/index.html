Introduction

Comprendre l'approche déclarative de GuidedStep en quelques minutes.

GuidedStep est une bibliothèque JavaScript vanilla qui ajoute des parcours guidés interactifs à vos applications web. Le principe est simple : vous balisez votre HTML existant avec des attributs gs-*, puis vous laissez la bibliothèque générer la carte contextuelle, l'overlay et la navigation.

Zéro dépendance

Aucun framework requis. Fonctionne partout, moins de 10 kb minifié.

100 % responsive

ResizeObserver recalcule automatiquement les positions à chaque redimensionnement.

Accessible (a11y)

Focus piégé, attributs ARIA et navigation clavier (Échap, Flèches).

Installation

Intégrez GuidedStep via votre serveur (fichiers locaux) ou directement en CDN.

Installer par IA — un prompt prêt à l'emploi

Copiez ce prompt et collez-le dans votre outil IA préféré (ChatGPT, Claude, Copilot, Gemini…). Il donne toutes les instructions pour installer le projet, implémenter le tutoriel GuidedStep, gérer le responsive des pages et gérer les formulaires si votre code est incompatible.

Prompt : installer GuidedStep + implémenter le tutoriel

Tu es un expert front-end. Intègre la bibliothèque
GUIDEDSTEP (guidedstep.js) dans mon projet web existant
pour créer un tutoriel / parcours d'onboarding interactif.
Suis scrupuleusement ces étapes :

1) INSTALLATION
- Récupère guidedstep.js et guidedstep.css (via npm :
  `npm install guidedstep.js`, ou en copiant les 2 fichiers
  dans le projet).
- Ajoute dans le `<head>` : le lien CSS
  `<link rel="stylesheet" href="guidedstep.css">`.
- Ajoute juste avant `</body>` :
  `<script src="guidedstep.js"></script>`.
- Ne casse ni ne renomme aucun fichier existant du projet.

2) IMPLÉMENTATION DU TUTORIEL (attributs gs-*)
- Ajoute l'attribut `gs-step="1", "2", "3"...` dans l'ordre
  sur les éléments à expliquer (boutons, menus, formulaires…).
- Sur chaque élément ajoute `gs-title="..."` (titre) et
  `gs-content="..."` (explication) si nécessaire.
- Optionnel : `gs-position="top|bottom|left|right|auto"` et
  `gs-transition="..."` pour la position de la carte.
- Initialise le tutoriel au chargement de la page :
  GuidedStep.init({ persist: true, overlayMode: 'blur',
  overlayBlur: 8, theme: { primaryColor: '#000000',
  borderRadius: '12px' } });
- Démarre le tutoriel : GuidedStep.start(0); (ou sur le clic
  d'un bouton via addEventListener).

3) BOUTON FLOTTANT DE RELANCE
- Ajoute l'attribut `gs-player="true"` sur la balise
  `<body>`
  pour afficher un bouton flottant "Revoir le guide" qui
  relance le tutoriel (GuidedStep.restart()).

4) RESPONSIVE DES PAGES
- Assure-toi que le tutoriel ET ma page restent parfaitement
  alignés sur mobile, tablette et desktop.
- Laisse les règles CSS mobiles de GuidedStep (media max-640px)
  en place ; ne les supprime pas.
- Vérifie que les cartes d'aide ne débordent pas de l'écran
  et restent lisibles sur petits écrans.

5) GESTION DES FORMULAIRES
- Si un élément du tutoriel est un FORMULAIRE ou un champ
  (input/select/textarea), NE BLOQUE PAS la saisie : place
  l'étape gs-step sur le bon élément visible, sans interférer
  avec les événements onchange/onsubmit.
- Si un code existant est INCOMPATIBLE avec GuidedStep
  (ex. conflit de z-index, element caché, scroll figé),
  corrige-le proprement : remonte le z-index de la carte,
  libère le scroll après coup, et assure la compatibilité
  sans casser les scripts existants.

6) VÉRIFICATIONS FINALES
- Teste la navigation (clavier : Échap, Flèches gauche/droite).
- Vérifie que la progression est sauvegardée (localStorage)
  et que le bouton flottant réapparaît après la fin du guide.
- Livre les fichiers modifiés + un bref résumé de ce qui a
  été changé.

7) DEMO / FICHIERS LOCAUX
- Le tutoriel ne se charge PAS via CDN : il utilise les
  fichiers locaux `guidedstep.css` et `guidedstep.js` placés
  dans le même dossier que la page (comme dans `demo.html`).
- Base-toi sur `demo.html` (la démo de référence) pour copier
  sa structure : lien `<link rel="stylesheet" href="guidedstep.css">`
  dans le `<head>` et `<script src="guidedstep.js"></script>`
  avant `</body>`.
- Si tu veux un aperçu fonctionnel, crée aussi une page
  `demo.html` qui charge ces fichiers locaux et lance le guide.

Utilisation de base

Deux étapes suffisent : baliser le HTML, puis initialiser en JavaScript.

1. Attributs HTML gs-*

Ajoutez ces attributs directement sur les éléments du DOM à mettre en avant :

Attribut Description Exemple
gs-step Ordre numérique de l'étape dans le parcours. gs-step="1"
gs-title Titre affiché en haut de la carte du tutoriel. gs-title="Bienvenue"
gs-content Texte descriptif de l'étape (HTML basique autorisé). gs-content="Ceci est le menu"
gs-position Position préférée de la carte (top, bottom, left, right, auto). gs-position="bottom"

2. Bouton flottant de relance — gs-player="true"

Pour afficher automatiquement un bouton flottant (FAB) « Revoir le guide », ajoutez simplement l'attribut gs-player="true" sur l'élément <body> :

index.html HTML 
<body gs-player="true">
  <!-- Cibles du tutoriel avec gs-step -->
  <button gs-step="1" gs-title="Bienvenue"
          gs-content="Cette page vous guide pas à pas">
    Découvrir
  </button>
</body>

Comment ça marche ?

Le bouton flottant apparaît dès le chargement du script. Un clic relance le tutoriel depuis la première étape (appelle GuidedStep.restart()). Il est masqué automatiquement pendant que le guide est actif, puis réaffiché à la fin. L'attribut est optionnel : sans lui, aucun bouton n'est créé et le guide ne démarre que via JavaScript. Le bouton utilise la classe .guidedstep-fab pour la personnalisation.

3. Initialisation JavaScript

app.js JavaScript 
// 1. Initialiser avec les options souhaitées
GuidedStep.init({
  persist: true, // Sauvegarde la progression dans le localStorage
  overlayMode: 'blur', // 'color' = voile coloré | 'blur' = flou d'arrière-plan
  overlayBlur: 8, // Intensité du flou en px (mode 'blur')
  theme: {
    primaryColor: '#000000',
    borderRadius: '12px',
    overlayColor: 'rgba(0, 0, 0, 0.65)', // Voile en mode 'color'
    overlayTint: 'rgba(0, 0, 0, 0.3)', // Léger voile en mode 'blur'
  },
});

// 2. Démarrer le tutoriel (au chargement ou au clic d'un bouton)
document.getElementById('start-tour').addEventListener('click', () => {
  GuidedStep.start(0); // Commence à l'index 0
});
Référence

API JavaScript

Le contrôle du parcours repose sur un petit jeu de fonctions stables.

Fonctions de contrôle

  • GuidedStep.start(index) — démarre le parcours à l'index spécifié.
  • GuidedStep.next() — passe à l'étape suivante.
  • GuidedStep.prev() — revient à l'étape précédente.
  • GuidedStep.skip() — arrête et ferme le tutoriel immédiatement.
  • GuidedStep.restart() — réinitialise et redémarre depuis le début.

Callbacks de configuration

config.js JavaScript 
GuidedStep.init({
  // Déclenché au tout début du tutoriel
  onStart: (currentStep, allSteps) => {
    console.log('Début du parcours', currentStep);
  },

  // Déclenché lorsque la dernière étape est terminée
  onComplete: (allSteps) => {
    console.log('Parcours terminé avec succès');
  },

  // Déclenché si l'utilisateur clique sur « Passer » ou ferme
  onSkip: (currentStep, allSteps) => {
    console.log('Parcours abandonné à l\'étape', currentStep);
  },

  // Déclenché si un élément gs-step est introuvable ou caché
  // Retourner 'true' pour passer à la suivante, 'false' pour arrêter.
  onElementMissing: (stepObj, allSteps) => {
    console.warn('Élément manquant :', stepObj.selector);
    return true;
  },
});
Intégration

Intégration aux frameworks

GuidedStep fonctionne nativement partout. Voici les modèles recommandés.

React / Next.js

Dashboard.jsx React 
import { useEffect } from 'react';

export default function Dashboard() {
  useEffect(() => {
    if (typeof window !== 'undefined') {
      window.GuidedStep.init({
        persist: true,
        theme: { primaryColor: '#2563eb' },
      });
    }
  }, []);

  const startTour = () => window.GuidedStep.start(0);

  return (
    <div>
      <button onClick={startTour} className="btn-primary">
        Voir le guide
      </button>

      <nav
        gs-step="1"
        gs-title="Navigation"
        gs-content="Accédez à vos paramètres ici."
        gs-position="bottom"
      >
        <!-- Contenu de la nav -->
      </nav>
    </div>
  );
}

Angular

app.component.ts TypeScript 
import { Component, AfterViewInit } from '@angular/core';

// Déclarer la variable globale pour TypeScript
declare const GuidedStep: any;

@Component({
  selector: 'app-root',
  template: \`
    <button (click)="startTour()" class="btn">Guide</button>

      <h1>Mon App</h1>
    </header>
  \`,
})
export class AppComponent implements AfterViewInit {
  ngAfterViewInit() {
    GuidedStep.init({
      persist: true,
      storageKey: 'my_angular_app_tour',
    });
  }

  startTour() {
    GuidedStep.start(0);
  }
}
Personnalisation

Personnalisation CSS

Toutes les propriétés visuelles sont contrôlées par des variables CSS surchargeables.

Guidé par les variables CSS ci-dessous, GuidedStep s'adapte à votre charte graphique sans toucher au JavaScript — par exemple un style éditorial carré (borderRadius: 0) ou arrondi.

styles.css CSS 
/* Dans votre feuille de style globale */
:root {
  /* Couleurs */
  --guidedstep-primary: #000000;          /* Bouton principal        */
  --guidedstep-bg: #ffffff;               /* Fond de la carte         */
  --guidedstep-overlay: rgba(0, 0, 0, 0.7); /* Obscurcissement        */

  /* Formes */
  --guidedstep-radius: 0px;               /* 0px carré, 12px doux     */

  /* Typographie (optionnel) */
  --guidedstep-font-sans: 'Inter', sans-serif;
}

/* Style spécifique uniquement quand le tutoriel est actif */
body.guidedstep-active {
  cursor: default; /* Empêche les interactions en arrière-plan */
}

Accessibilité au cœur du produit, testée contre les bonnes pratiques WCAG.

Conforme aux bonnes pratiques WCAG

  • Le conteneur de la carte utilise role="dialog" et aria-modal="true".

  • Navigation clavier complète : Échap ferme, → / Entrée avance, ← recule.
